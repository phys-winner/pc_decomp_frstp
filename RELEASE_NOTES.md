# 0.3.1-dev

## Лаунчер и локализация

- Лаунчер, диагностика совместимости и настройки порта теперь поддерживают 15 языков, включая чешский и венгерский. Переведены подсказки и надписи сенсорного интерфейса.
- Для частной сборки можно добавить чешский и венгерский фанатские переводы игры из своих файлов. Каждый добавленный язык можно выбрать в меню игры. APK из `pub` включает переводы лаунчера и настроек порта.

## Графика и совместимость

- Экспериментальные режимы Native Vulkan (PanVK) и DXVK (PanVK) проверяются на всех Mali и Immortalis начиная с Android 11. Для встроенного драйвера нужны страницы памяти 4 КиБ. На других устройствах можно импортировать совместимый PanVK и запустить проверку.
- Нативный Vulkan пропускает команды отрисовки и вычислений, если их шейдерам нужны возможности, которых нет у драйвера. Это снижает риск сбоя и может привести к отсутствию отдельных эффектов.
- Расширена диагностика нативного Vulkan. Трассировка может охватывать несколько кадров и фиксировать вычислительные команды, копирование и чтение текстур.

## Сенсорный интерфейс

- Снимок интерфейса для сенсорного управления обновляется реже в простое, чтобы уменьшить нагрузку на главный поток.
- При увеличенном масштабе интерфейса проверка видимости в книге законов выполняется только для элементов, используемых сенсорным управлением.

APK `Frostpunk-0.3.1-dev-<commit>.apk` для Android 11+ и ARM64. Код версии `6`. Для запуска нужны поддерживаемые файлы Steam-версии Frostpunk.

# 0.3-dev

## Графика и совместимость

- В лаунчере появился экспериментальный нативный рендер Vulkan. При выключенной опции игра использует DXVK, как и раньше. Выбор применяется при следующем запуске игры.
- После сбоя нативного рендера безопасный режим включает последовательную компиляцию в драйвере. После повторного сбоя игра возвращается к DXVK. В нативном режиме FSR 3.1 заменяется FSR 1.
- Исправлены пропавшие портреты разведчиков и лишняя дуга на индикаторе температуры на Mali-G615. Доработана обработка загрузки ресурсов и восстановления поверхности в Vulkan.
- Для Adreno 830 доступен системный драйвер Qualcomm, если Turnip не запускается и драйвер поддерживает Vulkan 1.3 и нужные BC-текстуры. Исправлены повторные попытки переключения в полноэкранный режим в DXVK.

## Сенсорное управление и интерфейс

- В режиме строительства курсор фиксируется в центре. Справа доступны кнопки прокладки и сноса дорог, подтверждения и отмены. В интерфейсе Switch удержание кнопки строительства открывает сектор кругового меню.
- Щипок плавно приближает или отдаляет камеру. Повторный жест на максимальном отдалении открывает карту мира. Скорость игры меняется свайпом по шкале времени, а первое касание показывает подсказку.
- Уведомления можно свернуть до значков. Исправлены расположение элементов верхней панели, появление кнопок карты мира и маяка, масштаб графиков экономики и высота вкладки «Рабочие».
- Доработаны книга законов, меню сценариев и бесконечного режима, подписи и субтитры. При смене интерфейса Switch игра предлагает перезапуск.
- На первом запуске порт активирует бесплатный памятник строителям. Его можно отключить в настройках игры.
- Исправлено пропадание нажатия «Играть», если лаунчер обновлял экран во время касания. Добавлена диагностика зависаний при остановке вывода кадров.

APK `Frostpunk-0.3-dev-<commit>.apk` для Android 11+ и ARM64. Версия пакета `0.3-dev`, код версии `5`. Для запуска нужны поддерживаемые файлы Steam-версии Frostpunk.

# 0.2-dev

- Имя APK включает восемь символов хеша коммита: `Frostpunk-0.2-dev-<commit>.apk`.
- Кнопка Releases в разделе о приложении заменена на Telegram с каналом портов.

- Лог рендеринга записывается в `/sdcard/Frostpunk/render.log` только при
  включённом мониторинге вылетов. Отчёт о сбое читает лог из этого же места.

- Детализация моделей и качество зданий по умолчанию выставлены на минимальные
  значения. Ранее сохранённые пользовательские настройки сохраняются.
- Загрузку внешнего драйвера можно прервать кнопкой «Прервать» в панели задач
  лаунчера. HTTP-соединение закрывается, временный файл удаляется, выбранный
  драйвер не меняется при отмене.
- Скачанные драйверы сохраняются локально и повторно используются без сети.
  Внизу лаунчера появляется кнопка удаления неиспользуемых внешних драйверов;
  активный драйвер исключён из очистки.

- Игра поддерживает только альбомную и обратную альбомную ориентации,
  в том числе при подключении геймпада; портретный режим отключён.

- Исправлен запуск со старыми UI-патчами: актуальные `port-ui.*` генерируются
  из текущих настроек и переводов, входят в APK и проверяются по SHA-256.
  Они имеют приоритет над ресурсами игрового ZIP и старыми `port-settings.*`.
- В лаунчере указано имя встроенного драйвера `purple-turnip T30 (Mesa)`;
  в APK добавлены текст MIT-лицензии Mesa и сведения об источнике драйвера.

- Драйвер purple-turnip T30 хранится в APK в одном экземпляре: `libpurple_turnip.so`.
  Удалены одинаковые копии для SM8250 и других Adreno; проверка GPU и игра используют
  одну библиотеку. Загрузка пользовательских драйверов сохранена.

- При первом открытии лаунчера на устройствах с общим доступным Android объёмом
  ОЗУ 7,5 ГиБ или меньше показывается предупреждение о возможных закрытиях игры.
  После подтверждения оно не повторяется, пока сохранены данные приложения.

- Добавлен монитор вылетов в отдельном процессе: сообщения о нативных сбоях,
  ошибках Java и завершении игры Android из-за нехватки памяти. Монитор можно
  отключить в лаунчере; штатный выход не вызывает сообщение о сбое.
- Добавлены режимы расхода памяти: «Авто», «Обычный», «Меньше» и «Минимум».
  Автоматический режим выбирает «Меньше» при объёме RAM ниже 7 ГиБ и «Минимум»
  ниже 5 ГиБ. Профили ограничивают разрешение и упрощают графику без перезаписи
  сохранённых пользовательских настроек.
- Добавлены настройки детализации моделей и качества моделей зданий;
  доработано упрощение геометрии и применение графических профилей.
- В меню выходного разрешения показываются размеры в пикселях и процент масштаба.
- Убраны принудительный пропуск обновления города на паузе и подмена кадра
  сохранённым изображением. Восстановлен обычный путь обновления и отрисовки мира.
- Поворот экрана по датчику ограничен двумя альбомными ориентациями,
  включая использование телескопических контроллеров.
- Встроенный драйвер Adreno обновлён до purple-turnip T30. В лаунчер добавлены
  просмотр релизов и загрузка драйверов Turnip из выбранного репозитория.
- Добавлено предложение скачать отсутствующие пакеты интерфейса; проверка
  обновлений приложения теперь учитывает предварительные dev-релизы GitHub.
- Доработаны проверка целостности ZIP, диагностические отчёты и обработка
  файлов игры. CRC игрового runtime использует нативную реализацию ARM64.
- Сборка выпуска пересобирает актуальный D3D11-мост и включает текущие
  библиотеки и метаданные Turnip вместо копий из старого базового APK.

APK: `Frostpunk-0.2-dev-<commit>.apk` (8 символов хеша); version code: `4`.

Экспериментальный выпуск для Android 11+ / ARM64. Для игры по-прежнему нужны
совместимый Vulkan-драйвер и собственные поддерживаемые файлы Steam-версии.
Предупреждение лаунчера о несовместимом GPU больше не блокирует попытку запуска;
это не гарантирует работу игры на таком устройстве. Экономия памяти не исключает
завершения процесса Android. Полная проверка сценариев и длительной игры не выполнена.
Сборка использует локальные ранее сгенерированные AOT-объекты и не воспроизводится
из одного чистого клона.

# 0.1-dev

Experimental Frostpunk ARM64 port for Android with touch controls and Vulkan.

- Native ARM64 execution through static recompilation and a native host runtime.
- D3D11 rendering through DXVK, Turnip on Adreno, and supported system Vulkan on
  Mali and PowerVR.
- Localized GPU compatibility checks before launch.
- Touch camera controls, building placement, roads, keyboard input, and in-game
  port settings when the matching UI resources are present.
- Folder import and direct reads from compatible stored ZIP archives.
- On-device DXT-to-ASTC preparation, quality checks, and launch after conversion.
- PC snow and terrain by default, independent Switch graphics groups, and texture
  quality selection.
- System-language defaults, guarded 200% UI scale, and saved-setting preservation.

Requires Android 11+, compatible ARM64 Vulkan 1.3 hardware, and the supported Steam
PC game files supplied by the player. Original game files and optional extracted
assets are not distributed here. Device and scenario coverage is incomplete;
performance and long-session stability vary. Clean-clone APK reproduction is not
yet provided.

APK: `Frostpunk-0.1-dev.apk`

Package: `com.frostpunk.staticrecomp`

Version code: `2`

Suggested repository description:

> Experimental Frostpunk ARM64 Android port via static recompilation, with Vulkan rendering and touch controls.
