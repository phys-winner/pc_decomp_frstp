# Frostpunk для Android 0.4-dev

Изменения относительно `0.3.2.1-dev`, включая ранее локальные изменения `0.3.3-dev`. Код версии Android — `10`.

- Исправлены масштабирование и перемещение камеры после жестов двумя пальцами и строительства; звук метели плавно меняется вместе с масштабом.
- Увеличены шрифты и доработана компоновка мобильного интерфейса: дневники разведчиков, карта, технологии, законы, сведения о зданиях и другие панели.
- Исправлены отображение счётчика FPS поверх игры и ложный отчёт о сбое после закрытия игры через список последних приложений.
- Добавлены проверки границ таблиц игровых сущностей для предотвращения вылетов при очистке строительного предпросмотра.
- В APK оставлен нативный Vulkan с системным драйвером, Turnip и PanVK; библиотеки DXVK и FSR 3 исключены. Добавлены обходы проблем шейдеров Qualcomm и улучшена обработка сбоев рендерера.
- Кэш пайплайнов Vulkan сохраняется в фоне и используется при следующих запусках.
- Обновлены проверки совместимости, подготовка текстур, сообщения лаунчера и переводы; добавлен включённый по умолчанию переключатель ADPF.

# Frostpunk для Android 0.3.2.1-dev

Исправления относительно `0.3.2-dev`. Код версии Android — `8`.

- Исправлен вылет лаунчера при показе сведений о совместимости. На всех 15 языках добавлены сообщения о системном драйвере Qualcomm и отсутствии поддерживаемых форматов текстур. Если отдельный перевод отсутствует, лаунчер использует английский текст.
- При подключении игрового ZIP без сжатия лаунчер сохраняет отметку о целостности только после проверки CRC-32 всех файлов. Старые отметки больше не пропускают проверку, а новая отметка привязана к конкретному файлу архива и индексу.
- Добавлены регрессионные проверки полноты переводов и обнаружения повреждённого ZIP со старой отметкой о целостности.

# Frostpunk для Android 0.3.2-dev

Полный список изменений относительно `0.3.1-dev`. APK для ARM64, Android 11 и новее. Код версии `7`, пакет `com.frostpunk.staticrecomp`. Для запуска нужны поддерживаемые игровые файлы Steam-версии Frostpunk.

## Рендереры и драйверы

- Нативный Vulkan стал основным рендерером. Системный Vulkan, Vulkan (Turnip) для поддерживаемых Adreno и Vulkan (PanVK) для Mali и Immortalis проверяются отдельно. Сохранены три варианта DXVK: системный, Turnip и PanVK.
- Лаунчер определяет совместимость по фактически загруженному драйверу, версии Vulkan, очередям, расширениям, возможностям и форматам. Adreno с системным Vulkan 1.1 может запускать нативный рендерер через совместимый Turnip. В карточках выбора видны причины недоступности режима и результаты проверки каждого драйвера.
- Для PanVK проверяются идентификаторы GPU и драйвера, а также создание логического Vulkan-устройства. Встроенная сборка по-прежнему требует страницы ядра 4 КиБ. Лаунчер поддерживает импорт совместимых пользовательских драйверов.
- Встроенный PanVK содержит дополнительные изменения на основе r10. Обновлены обработка нехватки памяти тайлера CSF, путь совместимости с Android gralloc и диагностика. Для совместимых устройств доступна настройка линейного gralloc.
- Обновлены выбор, загрузка и импорт выпусков Turnip. В комплекте указывается purple-turnip T30. Выбор драйвера и результаты проверок привязаны к реальному провайдеру.
- Добавлены переключатели обходов для Mali и PowerVR. На Mali можно повторно задать динамическое состояние в каждом проходе. На PowerVR можно компилировать шейдеры последовательно.
- При сбое нативного Vulkan открывается отчёт. Можно повторить запуск или выбрать другой рендерер.

## Кадры, стабильность и память

- В нативном Vulkan добавлены метки завершения GPU, проверки fence и счётчики синхронизации. Уточнены ожидания, повторное использование ресурсов и обработка флагов D3D11 Map, в том числе неблокирующего режима. В журнал выводятся данные о кадрах, ожиданиях и состоянии очереди.
- DXVK получил запасной режим для устройств без поддержки каркасной растеризации и более осторожное сохранение кэша пайплайнов при потере устройства. Изменены настройки задержки кадров и числа потоков компиляции в профиле производительности.
- Оба рендерера используют общий алгоритм уменьшения некоторых крупных односоставных RGBA8/BGRA8-текстур интерфейса. По умолчанию длинная сторона ограничена 2048 пикселями. Нативный Vulkan учитывает уменьшение при обновлении и копировании таких ресурсов.
- Улучшены отчёты о памяти и потере Vulkan-устройства. В инструментах профилирования добавлена помощь в разборе нативных стеков, CPU, времени кадра и GPU.

## Текстуры и игровые данные

- Проверка текстур учитывает возможности выбранного драйвера для DXT1, DXT3, DXT5 и ASTC 6×6. Нативный Vulkan и DXVK читают совместимый кэш текстур. Лаунчер проверяет, покрывает ли кэш выбранное качество Switch или ПК.
- Доработаны предложение ASTC перед запуском, продолжение запуска после конвертации, восстановление и очистка кэша, оценка места и отображение прогресса. Исходные игровые файлы сохраняются.
- Добавлены распознавание, размеры блоков, чтение и экспериментальная конвертация ETC2 RGB/RGBA через etcpak. В этой конфигурации выпуск предлагает игрокам ASTC. ETC2 оставлен в коде для проверки.
- Уточнены обработка размеров, смещений и шагов строк сжатых текстур, проверка архивов и их записей. Добавлены инструменты инвентаризации текстур и тесты форматов, включая повреждённые входы.
- Лаунчер уточняет проверку источника игровых данных, работу со Store ZIP, чтение из архива и состояние установки. Добавлена отдельная проверка MD5 для архивов, когда у дистрибутива задана контрольная сумма. Доработаны выбор файлов, проверка доступного места и прогресс операций.

## Управление и производительность CPU

- Вращение и зум двумя пальцами снова работают вместе. После поворота сохраняется режим камеры, в котором обрабатывается масштабирование.
- Курсор строительства достигает краёв карты. Когда камера упирается в границу, оставшаяся часть жеста сдвигает точку прицела по земле. В разработке проверялись сценарии и карты бесконечного режима.
- Нативные ARM64-реализации взяли на себя запрос видимости, обход сущностей и поиск по GUID. Добавлены предварительная загрузка данных и пути возврата к транслированным функциям при особых условиях.
- Частые импорты Win64 получают прямые обработчики. Оптимизированы участки строковых, математических и оконных операций, синхронизации, локализации и CRC. Сокращена работа при обходе мобильного интерфейса.
- В статической трансляции исправлены атомарность операций x86 `LOCK` и `XCHG` по памяти, барьеры и обработка невыровненных адресов. Для упакованных SSE-сравнений исправлена обработка всех дорожек. Добавлены проверки сгенерированного кода и стресс-тест атомарных операций.

## Лаунчер и диагностика

- Добавлен настраиваемый игровой оверлей. Можно показать FPS и график времени кадров, CPU и частоты, загрузку и активные потоки, GPU и драйвер, используемый API, память, нагрев, игровой режим, батарею, мощность и параметры экрана. FPS рассчитывается по реально представленным кадрам.
- Доработаны карточки рендерера, драйверов и сведений об устройстве, навигация по файлам и интерфейс фоновых задач. Добавлена подсказка об игровом режиме HyperOS для подходящих устройств.
- Улучшены обработка запуска и возврата в лаунчер, диагностика каталогов и выбор места хранения, отображение состояния обновлений и отмена длительных операций.
- Отчёт о вылете использует причину завершения из Android, нативную метку сигнала, данные о памяти и хвосты журналов. Если Android предоставил трассировку, сохраняются данные tombstone. Отчёт доступен для копирования и отправки вручную.
- Сборка сохраняет чешскую и венгерскую локализации игры из проверенных входных файлов, а лаунчер сохраняет 15 языков. Добавлены переводы новых настроек обходов Mali и PowerVR.

## Сборка и лицензия

- Обновлён общий слой Android-лаунчера, включая проверку Vulkan, настройки релизов, нативные шаблоны и инструменты упаковки шейдеров. Обновлены тесты запуска, совместимости, аварийных журналов, архивов и форматов.
- Рецепт релиза пересобирает Java-лаунчер, приложение, DXVK, нативный Vulkan и хост, подключает нативные оптимизации CPU, атомарные исправления зависимостей и языковые обработчики. APK содержит идентификатор локального коммита. Для него записывается SHA-256.
- Применение **GPL-3.0-or-later** к оригинальному коду порта явно закреплено в `NOTICE` и SPDX-заголовках новых нативных исходников. В репозитории и APK присутствуют текст GPL и уведомления. Сторонние компоненты сохраняют свои лицензии. Добавлено уведомление BSD-3-Clause для etcpak.

# 0.3.1-dev

## Лаунчер и локализация

- Лаунчер, диагностика совместимости и настройки порта теперь поддерживают 15 языков, включая чешский и венгерский. Переведены подсказки и надписи сенсорного интерфейса.
- Для частной сборки можно добавить чешский и венгерский фанатские переводы игры из своих файлов. Каждый добавленный язык можно выбрать в меню игры. APK из `pub` включает переводы лаунчера и настроек порта.

## Графика и совместимость

- Экспериментальные режимы Native Vulkan (PanVK) и DXVK (PanVK) проверяются на всех Mali и Immortalis начиная с Android 11. Для встроенного драйвера нужны страницы памяти 4 КиБ. На других устройствах можно импортировать совместимый PanVK и запустить проверку.
- Нативный Vulkan пропускает команды отрисовки и вычислений, если их шейдерам нужны возможности, которых нет у драйвера. Это снижает риск сбоя и может привести к отсутствию отдельных эффектов.
- Расширена диагностика нативного Vulkan. Трассировка может охватывать несколько кадров и фиксировать вычислительные команды, копирование и чтение текстур.

## Сенсорный интерфейс

- Снимок интерфейса для сенсорного управления обновляется реже в простое, чтобы уменьшить нагрузку на главный поток.
- При увеличенном масштабе интерфейса проверка видимости в книге законов выполняется только для элементов, используемых сенсорным управлением.

APK `Frostpunk-0.3.1-dev-<commit>.apk` для Android 11+ и ARM64. Код версии `6`. Для запуска нужны поддерживаемые файлы Steam-версии Frostpunk.

# 0.3-dev

## Графика и совместимость

- В лаунчере появился экспериментальный нативный рендер Vulkan. При выключенной опции игра использует DXVK, как и раньше. Выбор применяется при следующем запуске игры.
- После сбоя нативного рендера безопасный режим включает последовательную компиляцию в драйвере. После повторного сбоя игра возвращается к DXVK. В нативном режиме FSR 3.1 заменяется FSR 1.
- Исправлены пропавшие портреты разведчиков и лишняя дуга на индикаторе температуры на Mali-G615. Доработана обработка загрузки ресурсов и восстановления поверхности в Vulkan.
- Для Adreno 830 доступен системный драйвер Qualcomm, если Turnip не запускается и драйвер поддерживает Vulkan 1.3 и нужные BC-текстуры. Исправлены повторные попытки переключения в полноэкранный режим в DXVK.

## Сенсорное управление и интерфейс

- В режиме строительства курсор фиксируется в центре. Справа доступны кнопки прокладки и сноса дорог, подтверждения и отмены. В интерфейсе Switch удержание кнопки строительства открывает сектор кругового меню.
- Щипок плавно приближает или отдаляет камеру. Повторный жест на максимальном отдалении открывает карту мира. Скорость игры меняется свайпом по шкале времени, а первое касание показывает подсказку.
- Уведомления можно свернуть до значков. Исправлены расположение элементов верхней панели, появление кнопок карты мира и маяка, масштаб графиков экономики и высота вкладки «Рабочие».
- Доработаны книга законов, меню сценариев и бесконечного режима, подписи и субтитры. При смене интерфейса Switch игра предлагает перезапуск.
- На первом запуске порт активирует бесплатный памятник строителям. Его можно отключить в настройках игры.
- Исправлено пропадание нажатия «Играть», если лаунчер обновлял экран во время касания. Добавлена диагностика зависаний при остановке вывода кадров.

APK `Frostpunk-0.3-dev-<commit>.apk` для Android 11+ и ARM64. Версия пакета `0.3-dev`, код версии `5`. Для запуска нужны поддерживаемые файлы Steam-версии Frostpunk.

# 0.2-dev

- Имя APK включает восемь символов хеша коммита: `Frostpunk-0.2-dev-<commit>.apk`.
- Кнопка Releases в разделе о приложении заменена на Telegram с каналом портов.

- Лог рендеринга записывается в `/sdcard/Frostpunk/render.log` только при
  включённом мониторинге вылетов. Отчёт о сбое читает лог из этого же места.

- Детализация моделей и качество зданий по умолчанию выставлены на минимальные
  значения. Ранее сохранённые пользовательские настройки сохраняются.
- Загрузку внешнего драйвера можно прервать кнопкой «Прервать» в панели задач
  лаунчера. HTTP-соединение закрывается, временный файл удаляется, выбранный
  драйвер не меняется при отмене.
- Скачанные драйверы сохраняются локально и повторно используются без сети.
  Внизу лаунчера появляется кнопка удаления неиспользуемых внешних драйверов;
  активный драйвер исключён из очистки.

- Игра поддерживает только альбомную и обратную альбомную ориентации,
  в том числе при подключении геймпада; портретный режим отключён.

- Исправлен запуск со старыми UI-патчами: актуальные `port-ui.*` генерируются
  из текущих настроек и переводов, входят в APK и проверяются по SHA-256.
  Они имеют приоритет над ресурсами игрового ZIP и старыми `port-settings.*`.
- В лаунчере указано имя встроенного драйвера `purple-turnip T30 (Mesa)`;
  в APK добавлены текст MIT-лицензии Mesa и сведения об источнике драйвера.

- Драйвер purple-turnip T30 хранится в APK в одном экземпляре: `libpurple_turnip.so`.
  Удалены одинаковые копии для SM8250 и других Adreno; проверка GPU и игра используют
  одну библиотеку. Загрузка пользовательских драйверов сохранена.

- При первом открытии лаунчера на устройствах с общим доступным Android объёмом
  ОЗУ 7,5 ГиБ или меньше показывается предупреждение о возможных закрытиях игры.
  После подтверждения оно не повторяется, пока сохранены данные приложения.

- Добавлен монитор вылетов в отдельном процессе: сообщения о нативных сбоях,
  ошибках Java и завершении игры Android из-за нехватки памяти. Монитор можно
  отключить в лаунчере; штатный выход не вызывает сообщение о сбое.
- Добавлены режимы расхода памяти: «Авто», «Обычный», «Меньше» и «Минимум».
  Автоматический режим выбирает «Меньше» при объёме RAM ниже 7 ГиБ и «Минимум»
  ниже 5 ГиБ. Профили ограничивают разрешение и упрощают графику без перезаписи
  сохранённых пользовательских настроек.
- Добавлены настройки детализации моделей и качества моделей зданий;
  доработано упрощение геометрии и применение графических профилей.
- В меню выходного разрешения показываются размеры в пикселях и процент масштаба.
- Убраны принудительный пропуск обновления города на паузе и подмена кадра
  сохранённым изображением. Восстановлен обычный путь обновления и отрисовки мира.
- Поворот экрана по датчику ограничен двумя альбомными ориентациями,
  включая использование телескопических контроллеров.
- Встроенный драйвер Adreno обновлён до purple-turnip T30. В лаунчер добавлены
  просмотр релизов и загрузка драйверов Turnip из выбранного репозитория.
- Добавлено предложение скачать отсутствующие пакеты интерфейса; проверка
  обновлений приложения теперь учитывает предварительные dev-релизы GitHub.
- Доработаны проверка целостности ZIP, диагностические отчёты и обработка
  файлов игры. CRC игрового runtime использует нативную реализацию ARM64.
- Сборка выпуска пересобирает актуальный D3D11-мост и включает текущие
  библиотеки и метаданные Turnip вместо копий из старого базового APK.

APK: `Frostpunk-0.2-dev-<commit>.apk` (8 символов хеша); version code: `4`.

Экспериментальный выпуск для Android 11+ / ARM64. Для игры по-прежнему нужны
совместимый Vulkan-драйвер и собственные поддерживаемые файлы Steam-версии.
Предупреждение лаунчера о несовместимом GPU больше не блокирует попытку запуска;
это не гарантирует работу игры на таком устройстве. Экономия памяти не исключает
завершения процесса Android. Полная проверка сценариев и длительной игры не выполнена.
Сборка использует локальные ранее сгенерированные AOT-объекты и не воспроизводится
из одного чистого клона.

# 0.1-dev

Experimental Frostpunk ARM64 port for Android with touch controls and Vulkan.

- Native ARM64 execution through static recompilation and a native host runtime.
- D3D11 rendering through DXVK, Turnip on Adreno, and supported system Vulkan on
  Mali and PowerVR.
- Localized GPU compatibility checks before launch.
- Touch camera controls, building placement, roads, keyboard input, and in-game
  port settings when the matching UI resources are present.
- Folder import and direct reads from compatible stored ZIP archives.
- On-device DXT-to-ASTC preparation, quality checks, and launch after conversion.
- PC snow and terrain by default, independent Switch graphics groups, and texture
  quality selection.
- System-language defaults, guarded 200% UI scale, and saved-setting preservation.

Requires Android 11+, compatible ARM64 Vulkan 1.3 hardware, and the supported Steam
PC game files supplied by the player. Original game files and optional extracted
assets are not distributed here. Device and scenario coverage is incomplete;
performance and long-session stability vary. Clean-clone APK reproduction is not
yet provided.
